# MD_decomposer

将一个正整数时值拆分为若干个可用数字表示的时值，并给出不同优化目标下的分解结果。

本程序只处理整数，不会把数字转换成完整的简谱音符或节奏符号。请先将音符时值换算成统一的整数单位，再输入。

## 环境要求

- Python 3.6 或更高版本
- 无需安装第三方依赖

## 运行

在项目目录中运行：

```bash
python MD_decomposer.py
```

按提示输入一个正整数。例如输入 `10`：

```text
请输入预分解的数字：10
最优分解： 10 = 6 + 4
其最小块值为：4

项数最少分解： 10 = 6 + 4
其最小项数为：2

标准差最小分解： 10 = 6 + 4
其最小标准差为：1.000000
```

## 分解规则

候选块的数值形式为：

```text
2^s × (2^r - 1)
```

其中 `s` 为非负整数，`r` 为正整数。每个不同数值的候选块在一次分解中最多使用一次；输出的分解项相加等于输入值。

程序依次显示：

1. **最优分解**：尽量提高分解中最小一项的值。
2. **项数最少分解**：使用最少的项数；在找到的最少项数方案中，优先选择最小项较大的方案。
3. **标准差最小分解**：使各分解项的总体标准差最小。

每种目标显示一个代表性结果，不是列出所有可能分解。

## 输入范围

请输入大于零的整数。输入小数、文本、零或负数不属于程序支持的输入范围。
